## Отличия от примеров методички

Номера строк соответствуют фактическим исходникам, а не условным строкам 15, 25,
35 из примеров. Источник каждого номера защищён SHA-256. К восьми базовым записям
добавлены IDOR, NULL pointer, постоянный ключ и открытое хранение паролей.

CVSS пересчитан по явно указанным векторам модели. SQLi Python: 8.2 вместо 9.8;
XSS Python/JS: 6.1 вместо 8.2; переполнение C++: 5.5 вместо 9.5; командная инъекция
C++: 7.8 вместо 9.8; SQLi JS: 5.3 вместо 9.8. Format String C++ 7.8 и Command
Injection JS 9.8 совпадают с образцом. Значения из образца нельзя переносить без
условий атаки. Допущения изложены в отчёте 6, полный вектор есть в каждой записи.

Для консольного C++ поле owasp равно N/A с пояснением области применения.
Отдельное owasp_assignment сохраняет A06 для переполнения, A03 для форматной строки
и командной инъекции, A05 для NULL pointer, как в методичке. Это сопоставление
образца, а не утверждение, что любая ошибка памяти относится к устаревшим компонентам.

Примеры CVE не являются номерами уязвимостей учебного стенда. Вместо неподтверждённых
или менее подходящих примеров документа приведены аналоги с доступными источниками.
Для каждой записи cve_relation описывает различия. Баллы CVE не выдаются за баллы
учебной находки; широкие аналоги для переполнения и IDOR явно обозначены.

По [официальному архиву CWE Top 25 2025](https://cwe.mitre.org/top25/archive/2025/2025_cwe_top25.html)
CWE-476 занимает место 13 и имеет 0 CVE в колонке KEV. Значения 14 и 21 в методичке
не использованы как факты. OWASP выбран в редакции 2021, соответствующей заданию.

## Подтверждение и ограничения

Первоначальный комплект содержит 30 успешных динамических сценариев Ubuntu.
Дополнение от 17 сентября 2026 года содержит 4 запуска NULL-примера, 2 статические
проверки Python и 4 воспроизведения сохранённых HTML-ответов в Edge. Эти серии
разделены и имеют собственные протоколы; общий счёт 40 не означает 40 DAST-тестов.
Браузерное воспроизведение подтвердило исполнение маркера XSS в уязвимых ответах
и отсутствие исполнения в исправленных. Повторный сквозной запуск веб-серверов
в браузере, обычный ICMP в fixed JS и запуск Arch-скрипта не заявляются.

Неизвестные ФИО и группа оставлены для заполнения участниками. Задание не требует
выдуманных скриншотов, ZAP-отчёта или истории индивидуальных запусков. Полный аудит
зависимостей, CSRF и rate limiting остаются за пределами проверенных сценариев.
