# Датасет уязвимостей

Двенадцать находок в трёх языках, девять классов CWE. Это целевой учебный
датасет, а не исчерпывающий перечень всех ошибок и зависимостей.

| Поле | Значение |
|---|---|
| vuln_id | Стабильный ID находки PY, CPP или JS |
| language, file, line | Язык и фактическое расположение дефекта; строки от 1 |
| source_sha256 | Хеш исходника, к которому относится line |
| severity, cvss | Уровень и балл учебной модели, не оценка сканера |
| cvss_version, cvss_vector, cvss_type | Версия, полный вектор и явное обозначение модели |
| cwe_id, cwe_name | Класс дефекта |
| owasp, owasp_version | Категория редакции 2021; N/A для консольного C++ |
| cve_example, cve_source, cve_relation | Пример из другого продукта, источник и отличие |
| description, recommendation | Причина, наблюдение и исправление |
| evidence, status, evidence_scope | Относительный путь к протоколу и предел доказательства |

JSON хранит числа типизированно, CSV — их строковые представления. Разделитель CSV —
запятая, кодировка UTF-8, кавычки обрабатываются стандартным CSV-парсером.
N/A означает неприменимость, а не отсутствие уязвимости. Статус confirmed_static обозначает проверку исходников;
confirmed_http_and_browser_replay — HTTP-протокол и исполнение сохранённого HTML
в изолированном браузере, без повторного запуска сервера.

Сборка: `python scripts/build_dataset.py` из корня репозитория. Требуются уже готовые
протоколы динамических проверок, которые входят в комплект. Скрипт не запускает атаки
и не скачивает CVE. Подробные допущения CVSS находятся в `reports/Прядко/report.md`;
самостоятельная экспертная оценка — в `expert_assessment.md`.

В cwe_mapping.csv поле rank_2025 содержит место в архиве CWE Top 25 2025;
пустое значение для CWE-134 означает отсутствие в Top 25. Источник указан в rank_source.

## Дополненные поля

owasp_assignment хранит категории из методички отдельно от применимости OWASP
к консольному C++; owasp_note объясняет различие. verification_method отличает
статическую проверку от динамической. browser_evidence ссылается на исполнение
сохранённого HTTP-ответа; его SHA-256 проверяется при сборке.
cwe_mapping.csv содержит требуемое typical_impact. Общее имя CWE-79 — Cross-site
Scripting, а конкретные строки различают Stored и Reflected XSS.
